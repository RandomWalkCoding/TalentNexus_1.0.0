# TalentNexus 人才与组织智能运营工作台 PRD

**版本**：v1.0 需求更新版
**日期**：2026-10-10
**状态**：新增能力待开发

## 1. 背景、目标与现状

TalentNexus 已有工作台、情报、竞对、人才库、摸排任务、触达战役、Mapping、职级体系、市场薪酬、登录与管理台等基础页面。现有 AI 快讯展示已有情报，汇率与 PPP 为版本化演示参数，触达尚未接入真实邮箱收发。本 PRD 定义下一阶段需求，不能把规划能力视为已上线能力。

目标是形成可追溯的工作链：**情报采集 → 组织摸排 → 岗位与职级对标 → 薪酬判断 → 人才寻访 → 邮件触达 → 反馈回流**。AI 负责提取、归纳、建议和草稿；关键事实、计算依据及对外邮件保留人工核验和记录。

| 成功指标 | 定义与验收 |
|---|---|
| 组织档案完整率 | 已核实字段/必填字段，可按公司和地区查看缺失项 |
| 情报可追溯率 | 自动采集情报 100% 具有来源、采集时间和核验状态 |
| 寻访转化漏斗 | 入库、筛选、触达、回复、有效沟通人数口径一致 |
| 邮件同步状态 | 展示最近成功时间、失败原因和重试结果 |
| 宏观数据新鲜度 | 汇率、PPP 展示来源、发布日期和过期状态 |

## 2. 用户和权限

| 角色 | 主要任务 | 权限重点 |
|---|---|---|
| 管理员 | 配置数据源、模型、邮箱、角色及审计 | 配置和全量读写 |
| HR/招聘负责人 | 管理寻访、审核分析、审批触达 | 负责范围读写和邮件发送 |
| 研究员 | 收集组织与领队情报、核验来源 | 情报与摸排读写、邮件草稿 |
| 业务管理者 | 查看组织、职级、薪酬和进度 | 授权范围只读、报告导出 |

联系方式、邮件正文、薪酬数据按角色和任务授权。查看敏感详情、导出、模型调用和邮件发送均记录操作者、时间、对象。密钥只在服务端保存。

## 3. 模块与业务流程

保留现有全局壳层、深浅主题、搜索、通知、登录、管理台及业务路由。新增能力挂在现有页面的子页或 Tab，具体路径在实现时固化。

| 模块 | 入口建议 | 产出 |
|---|---|---|
| 组织摸排 | `/research-tasks`、`/organizations/:id` | 公司、团队、区域、岗位、汇报关系、领队档案 |
| 薪酬结构分析 | `/compensation/analysis` | 固定、浮动、股权、津贴、雇主成本结构 |
| 职级对标 | `/job-levels`、`/mapping` | 外部与内部职级映射、证据、置信度 |
| 地区薪酬竞争力 | `/compensation/competitiveness` | 分位数定位、购买力视角、预算差距 |
| 人才寻访管理 | `/talent-pool`、`/search-projects` | 寻访项目、长短名单、阶段漏斗 |
| 触达与反馈 | `/outreach`、`/outreach/:id` | 邮件序列、发送状态、回复意向、后续动作 |
| AI 与数据源 | `/settings`、`/admin` | 模型、邮箱、汇率和 PPP 运行状态 |

用户创建摸排/寻访项目并指定目标公司、地区、职能、职级、负责人和期限。系统采集授权来源并去重，AI 提取组织关系和领队线索，研究员核实。用户完成职级和薪酬判断，建立人才名单，审核邮件后发送。回信和人工反馈更新人才阶段、组织情报与报表。数据缺失、来源冲突或任务失败时显示可处理状态，已确认记录不被自动结果静默覆盖。

## 4. 详细需求

### 4.1 组织摸排与领队情报

- **组织档案**：公司别名、行业、地区、规模、业务线、团队、岗位、汇报关系、近况、监测标签；组织树支持未知节点和历史版本比较。
- **摸排任务**：目标范围、负责人、优先级、计划时间、完成标准、进度、待核实清单、里程碑及成果链接；关联公司、岗位、人才、情报。
- **领队档案**：姓名、现/历史职位、负责区域和团队、公开经历、关键动态、公开联系渠道及与目标岗位关系。每条事实记录来源、采集时间、核验人、状态和可信度；弱线索不直接推断私人联系方式。
- 支持人工录入、表格导入和授权数据源定时采集。AI 提取实体与关系、归纳组织变化、提出待验证问题；冲突来源并列展示，人工选择采用版本并记录理由。
- 验收：公司详情能跳到原始来源；同名人员/公司可合并和拆分；关系修改留版本；报告导出包含来源。

### 4.2 薪酬结构分析

- 统一薪酬项：基本工资、短期奖金/提成、长期激励/股权、现金津贴、法定福利、额外福利和雇主税费；记录币种、周期、税前/税后、地区、样本时间及来源。
- 展示候选人所得、企业总成本及各项占比；按职级、地区和公司对比，标出缺失项。
- 股权估值、奖金目标值和实际发放值分开展示；无法可靠估值时标记未估值，不并入总现金。
- 图表展示样本量、P25/P50/P75、更新时间及口径；样本不足显示“数据不足”。导出附计算版本和数据快照号。

### 4.3 职级对标

- 保留 EX/M/P/S/T/U/W 序列和 Survey Grade 视图，增加外部公司职级与内部职级映射。
- 依据职责范围、团队规模、汇报层级、任职要求、管理跨度和薪酬带，支持一对多候选映射、置信度、证据及人工确认。
- 按公司、岗位、地区、序列、薪酬口径、时间筛选；查看差异与历史调整。AI 可建议映射并解释依据，人工确认后成为正式结果。无来源或样本不足须标记。

### 4.4 不同地区薪酬竞争力

- 输入职位/职级、地区、薪酬方案、币种和口径，输出相对市场 P25/P50/P75 的位置、目标分位差距、候选人到手金额及企业总成本。
- 保留本币原值、名义汇率、PPP 三种视角。名义汇率用于货币换算，PPP 用于购买力比较；明确来源与口径，不把 PPP 金额当作可支付工资。
- 地区卡与趋势图共用计算快照，显示样本时间、汇率日期、PPP 年份、税费假设版本。税费仍属版本化估算，结果标记“估算”。
- 支持方案 A/B、地区并排、预算反推及导出；样本不足或宏观数据过期时不输出确定性竞争力结论。

### 4.5 人才寻访管理

- 寻访项目记录职位画像、必需/加分条件、目标公司与地区、目标人数、计划、负责人及保密级别。
- 人才档案记录来源、经历、职级判断、能力标签、地区、联系方式及使用依据、最近核验时间、重复记录和关联项目。
- 阶段：待研究 → 长名单 → 短名单 → 待触达 → 已触达 → 已回复 → 沟通中 → 结束。每次变更记录负责人、原因和下次动作。
- 支持批量去重/分配、提醒、排除名单、候选人关注点及反馈摘要；跨项目显示历史接触，避免重复触达。AI 推荐需展示依据和待核实点，最终名单由人工确认。

### 4.6 邮箱自动化、触达与反馈

- 连接授权邮箱，显示身份、权限范围、最近同步、失效和重连状态。凭据加密存储，不进入日志或前端响应。
- 支持邮件模板、变量、草稿预览、发送窗口、频率限制、去重、退订/拒绝联系名单。首次触达与自动跟进审批策略可配置，默认负责人确认后发送。
- 邮件关联人才、项目、战役；状态包括待审、待发、已发、失败、退信、已回复、已停止。失败重试使用幂等键，防止重复发送。
- 回信按会话关联人才；AI 将回复归类为积极、待沟通、拒绝、自动回复或无法判断，提取时间意向和关注点。原文可查看，分类可纠正。
- 统计送达、回复、有效回复、预约、拒绝、退信、退订和人工反馈；按项目、模板、负责人及时间展示漏斗。拒绝或退订立即停止自动跟进。
- 邮件发送、回信分类修正、人工覆盖进入审计；敏感内容遵循配置的保留期限与删除策略。

### 4.7 AI 模型接入

- 配置模型提供方、版本、用途、额度、超时及回退策略。任务类型包括组织提取、关系归纳、薪酬/职级解释、人才匹配、邮件草稿和回复分类。
- 模型输入仅引用已授权数据。记录任务 ID、来源 ID、提示词及模型版本、运行时间、耗时、用量、输出和校验状态；结构化结果由服务端校验。
- 输出区分“来源事实”“推断”“建议”，附证据或标明无证据；低置信度进入人工审核。用户可接受、编辑、驳回并记录原因。
- 超时、限额或供应商不可用时支持重试与人工处理，原业务记录可继续使用；模型输出不得直接触发对外发送。

### 4.8 汇率与 PPP 自动更新

- 接入可配置且具备使用许可的数据源。汇率按工作日定时抓取，PPP 按来源发布周期更新；保存原始值、基准币、国家/地区、来源、发布日期、抓取时间、版本和校验结果。
- 校验格式、范围及异常波动，防重复导入。异常时使用最近已发布快照并显示过期告警；支持手动刷新、任务日志、重试、人工修正和回滚。
- 历史计算依快照号复现，新数据发布不改变旧报告。同一地区的名义汇率和 PPP 必须明确基准与年份，不能混用不同口径。

## 5. 数据、接口与交互

沿用 `/api/v1`、PostgreSQL 和现有权限/审计结构。新增实体建议为 `OrganizationUnit`、`LeaderProfile`、`Evidence`、`ResearchFinding`、`SearchProject`、`CandidateProject`、`CompensationSample`、`LevelBenchmark`、`MarketSnapshot`、`AiJob`、`EmailConnection`、`EmailMessage`、`OutreachSequence`、`OutreachFeedback`。现有 Company、Talent、ResearchTask、OutreachCampaign、MappingItem 可扩展；迁移保留已有数据与 ID。

接口覆盖组织树与证据、任务/项目及人才阶段、薪酬样本与竞争力计算、职级映射审核、AI 任务提交/状态/审核、邮箱连接与发送队列、回信同步与反馈修正、汇率/PPP 快照与刷新任务。列表统一分页、筛选、排序；写入进行权限校验、版本冲突处理及审计。

- 全局搜索覆盖公司、团队、领队、人才、任务和项目，结果按权限过滤。列表具备加载、空、错误、权限状态；返回详情后保留筛选和分页。
- 组织树、职级映射、薪酬图表和寻访漏斗可查看原始数据及口径。AI 结果显示来源、置信度、审核状态和纠错入口。
- 邮箱页明确展示实际收件人、时间、内容与审批状态；批量发送前预览数量及排除名单。
- 延续四张原始视觉基准：`mmexport1790043955354.jpg`、`mmexport1790043957837.jpg`、`mmexport1790043960106.jpg`、`mmexport1790043962275.jpg`。复用现有导航、主题、卡片、表格及图表，优先适配 1440×900，兼容 1280px 与窄屏。

## 6. 非功能要求

- **安全与隐私**：按最小权限访问人员资料及邮箱，后台任务也执行授权检查；日志脱敏，密钥加密，导出和删除可审计。
- **准确性**：薪酬、汇率、PPP 与 AI 分析显示口径、来源、版本和时间；计算可复现，正式报告不引用未核实的关键事实。
- **可靠性**：采集、模型、邮件、宏观更新使用后台任务和可观测状态；失败告警、重试及人工处理。发送去重，回信同步可断点续传。
- **性能**：常用列表正常网络下 3 秒内可交互；组织树、搜索、报表按需加载，长任务异步执行。
- **合规**：仅使用有授权或适当依据的数据；邮件遵守目标地区及企业触达规则，退订与删除请求可执行并留痕。

## 7. 分期与验收

| 阶段 | 范围 | 完成标准 |
|---|---|---|
| A 数据底座 | 组织/领队证据、寻访项目、薪酬样本、版本快照 | 可录入、查询、核验、去重、审计和导出 |
| B 分析能力 | 组织分析、职级映射、薪酬结构、地区竞争力、AI 审核 | 结果带证据与口径，可纠错；数据不足有明确状态 |
| C 自动化 | 邮箱连接、草稿审批、发送/回信同步、汇率/PPP 调度 | 真实邮箱闭环，失败重试不重发，快照可回滚 |
| D 运营闭环 | 反馈回流、漏斗报表、通知及质量评估 | 从组织线索到候选人反馈可逐项追溯 |

端到端验收：建立目标公司的领队摸排任务，导入带来源的组织信息；AI 提供待审核组织图；研究员确认岗位及领队关系；完成职级和薪酬对标，使用有日期的汇率/PPP 快照生成地区报告；将候选人加入寻访项目，审核邮件并发送；系统同步回信、更新阶段及漏斗。报告能复现当时的事实、计算和操作记录。

真实自动化上线前需确定业务配置：目标国家/地区及合法数据源、薪酬样本授权和最低样本量、汇率/PPP 来源与频率、AI 提供方和数据处理范围、邮箱提供方及发送审批、退订和数据保留期限。
