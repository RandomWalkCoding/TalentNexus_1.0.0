# 阶段 12：集成与发布准备

日期：2026-10-16。分支：`stage/12-integration-release`。状态：**本地集成与发布预检已完成；外部供应商、恢复演练和生产验收仍阻塞整阶段关闭**。

## 本轮落地

| 范围 | 改动 |
|---|---|
| 共享契约 | 全局搜索新增组织、领队、摸排任务和寻访项目类别；新增数据库就绪探测响应 schema |
| 搜索权限 | 按当前角色的资源读取权限决定是否查询；业务管理者不再通过搜索获得管理台用户信息。每类最多 5 条，只选择展示字段，统一排序；输入限制为 2—80 字符 |
| 搜索跳转 | 组织 `?unit=`、领队 `?leader=`、寻访 `?project=` 可直达详情；目标不在首页列表内时仍直接查询详情。领队详情展示团队、职务和证据，可跳转所属组织 |
| 认证与日志 | 非测试环境默认使用真实会话；演示登录只允许 development/test。CORS 改为精确 origin 配置；请求日志不输出原始 URL、Cookie 和授权头，统一错误日志使用错误码/requestId |
| 审计 | 扩展组织、领队、人才、项目、摸排任务、搜索、AI、宏观数据、Mapping/导出和薪酬敏感读取；记录细分资源 ID。沿用响应后写审计，失败记录日志，不提供事务性审计保证 |
| 运维 | 新增公开 `/api/v1/ready`：3 秒内数据库查询成功才返回 200，否则 503；health 继续只用于存活检查。API 限制 1 MiB 请求体、设置请求超时；进程停止时尝试关闭 Fastify/Prisma |
| Web 壳层 | 按权限过滤导航和模块搜索、保护已登记页面入口，展示实际姓名/角色。组织证据审核和项目阶段写操作按权限禁用。搜索提供加载/失败/重试，阻止过期请求覆盖结果 |
| 通知与会话 | 移除“数据已同步”的故障演示通知；加载/标记已读失败明确提示，标记失败保留未读状态；退出登录失败保留会话并提示 |
| 可访问性 | 搜索弹窗焦点约束及关闭后恢复焦点、嵌套弹窗优先处理顶层键盘事件、跳到主内容链接、减少动画偏好 |
| 体积 | Workflow、薪酬、管理台、AI 审核和对标页面按需加载；增加模块加载失败恢复入口。主包从本轮基线 559.86 kB / gzip 166.52 kB 降至约 498 kB / gzip 150 kB，属于构建产物证据，尚无真实运行性能测量 |
| 发布准备 | `db:status`、`ops:check` 只读预检、同源 HTTPS 代理示例，以及 [部署/备份恢复/回滚说明](./DEPLOYMENT_RUNBOOK.md) |

主要文件：`packages/contracts/src/index.ts`；`apps/api/src/app.ts`、`config/env.ts`、`modules/access.ts`、`modules/auth.ts`、`modules/search.ts`、`server.ts`；`apps/web/src/app/App.tsx`、`features/organization/*`、`features/search-projects/*`、`features/notifications/notifications-api.ts`、`features/operation-state.ts`、`styles/global.css`；`scripts/ops-preflight.ps1`、`deploy/nginx.conf.example`。
